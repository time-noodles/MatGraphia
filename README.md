# MatGraphia

固体化学・材料科学研究室向けの総合実験データ管理＆プロセス解析システムです。合成イベント・サンプル・測定データ・文献を一元管理し、XRD/Raman/PPMS/MPMS/SEM 等の全自動解析、3D 結晶構造可視化、試料間データ比較、仮登録（下書き保存）管理、Obsidian ノートへの自動エクスポートを提供します。

## 概要

MatGraphia は以下の研究ワークフローを包括的にサポートします。

```
物質 (CIF) ──→ イベント (合成) ──→ サンプル ──→ 測定 (全10種) ──→ 比較・傾向解析
                                                      ↓
                                              Obsidian ノート出力
```

主な機能:
- **直感的なカテゴリナビゲーション ＆ 1ページ統合登録フォーム**: 親カテゴリ（`🏠 メイン`, `📚 データ登録`, `📊 解析 ＆ データ管理`, `📋 ツール ＆ サポート`）別に整理されたサイドバーメニューと、スクロールが簡単な1ページ統合登録UI。
- **画面内ステップジャンプ (HTMLアンカースクロール)**: サイドバーからの操作で、目的の入力ステップへ一瞬でスムーズスクロール移動。
- **文献管理**: 論文・学内論文の DOI・PDF 付記およびタスク直接紐付け
- **物質情報管理**: CIF ファイルによる結晶構造登録・XRD シミュレーション・3D 可視化
- **イベント管理**: 固相合成 / CVT / アルゴンアニール / 脱インターカレーション等の合成手順・仕込み記録
- **サンプル管理**: 生成サンプルの追跡・**物理的保管場所ダイレクトリンク**
- **全10種 測定データ管理 ＆ 自動解析**:
  - XRD / SEM-EDX / 顕微鏡写真 / Raman / Laue / 電気化学 (CV, GCD) / PPMS 4端子 (超伝導 R-T, Tc) / PPMS 6端子 (ホール効果 RH, n, μ) / Shift電流 (Isc) / MPMS (FC/ZFC, μB/f.u.)
- **試料間データ比較 ＆ 重ね描き分析**: サンプル間・測定種別間でのマトリクス横並び比較およびプロット重畳解析
- **仮登録（下書き保存）＆ 元画面同等フルUI管理**: 全データ登録画面で1クリック仮登録に対応。データ管理画面で元画面と同じ完全な入力UIを用いて補完・本登録昇格が可能。
- **Obsidian 連携**: 全データを Markdown + 画像 + 双方向リンク（`[[]]`）として自動エクスポート

## 動作環境・インストール

### 必要要件

- Python 3.10 以上 (推奨: Python 3.12)
- Anaconda または Miniconda (推奨)

### インストール

```bash
# リポジトリのクローン（またはフォルダをコピー）
cd MatGraphia

# 依存ライブラリのインストール
pip install -r requirements.txt
```

主要な依存ライブラリ:

| ライブラリ | 用途 |
|---|---|
| streamlit | Web UI インターフェース |
| pymatgen / diffpy.Structure | XRD シミュレーション・結晶構造解析 |
| pybeads | XRD / Raman ノイズ・バックグラウンド除去 |
| pdfplumber | SEM EDX 定量分析 PDF レポート解析 |
| symple_plot | 学術論文スタイル プロット生成 |
| python-pptx | Laue 方位解析 PowerPoint ファイル連携 |
| scipy / numpy / pandas | 物理定数換算・最小二乗フィッティング・データ処理 |

## 起動方法 (ワンクリック簡単起動)

MatGraphia は Windows および Linux 環境でのワンクリック簡単起動に対応しています。

### Windows 環境
- **バッチファイル起動**: `launch.bat` をダブルクリック
- **サイレント起動 (コンソール画面非表示)**: `launch.vbs` をダブルクリック
- **デスクトップショートカット作成**: `Create_Windows_Shortcut.bat` をダブルクリックすると、デスクトップ上にアイコンが作成されます。

### Linux 環境
- **シェルスクリプト起動**: `./launch.sh` を実行
- **デスクトップショートカット**: `MatGraphia.desktop` ファイルをダブルクリック

### Python / ターミナルコマンド
```bash
# クロスプラットフォーム Python ランナー
python run.py

# または標準 Streamlit コマンド
streamlit run app.py
```

初回起動時に `data/` ディレクトリと SQLite データベース (`data/matgraphia.db`) が自動作成されます。

## データモデル

```
Literature (文献) ─── タスク紐付け ───→ Task (タスク/サブタスク)
     ↑ 参照
Event (イベント) ─── 入力サンプル ───→ Sample (サンプル) ─── 保管場所 ──→ Location Badge
     ↓ 生成                                    ↓ 測定
  Sample ──────────────────────────────→ Measurement (測定)
                                               ↓ 比較
Material (物質) ──────────────────────→ Comparison (専用データ比較)
```

### エンティティ一覧

| エンティティ | 説明 |
|---|---|
| **Literature** | 参考文献（論文・学内論文）|
| **Material** | 物質情報（CIF ファイル・物性値・XRD シミュレーション）|
| **Event** | 合成実験の手順・仕込み・昇温条件 |
| **Sample** | イベントから得られたサンプルおよび保管場所 |
| **Measurement** | サンプルの測定データ（全10種）|
| **Task** | 親タスク / 小タスク（サブタスク）および締め切り管理 |
| **DeveloperLog** | アプリ内開発フィードバック・自動エラーログ |

## ナビゲーション ＆ 各ページの使い方

### 🧭 サイドバーカテゴリナビゲーション
- 機能が 4 つの親カテゴリ（`🏠 メイン ＆ 検索`, `📚 データ登録`, `📊 解析 ＆ データ管理`, `📋 ツール ＆ サポート`）に分かれており、目的のページを選択できます。
- 登録画面ではサイドバーに「🚀 画面内ステップジャンプ」が表示され、目的の入力セクションへ直接アンカースクロール移動できます。

### 🏠 ホーム (ダッシュボード)
- 全登録データ数（文献・物質・イベント・サンプル・測定・タスク）のメトリクス表示。
- 直近の実験タスク・下書き保存（仮登録）データへのクイックアクセス。

### 🔍 グローバル検索
- キーワードやタグにより、全エンティティを横断検索・絞り込み表示。

### 📚 文献の登録
- DOI、論文タイトル、著者、PDF アップロードの登録。タスクへの紐付けに対応。

### 🧪 物質の登録
- 化学式・CIF ファイルアップロード。
- 自動 XRD シミュレーション生成および `symple_plot` プロット作成。

### ⚗️ イベントの登録
- 合成タイプ（Solid-State, CVT, Ar-Annealing, Deintercalation）に応じたパラメータ・原料仕込み表・昇温プロファイルの記録。
- 秤量・配分元素のリアルタイム M.W. (原子量) 自動計算機能。

### 📌 サンプルの登録 ＆ 保管場所リンク
- イベントから生成したサンプルの登録。
- 物理的保管場所（例: `📍 デシケーター Box #A2`）の直感リンク化。クリックで同場所に保管されているサンプルを即座に検索。

### 📊 測定データの登録 (全10種対応)
- 各測定機器からの生データアップロードおよび自動パース・解析（詳細は [プラグインシステム](#プラグインシステム) を参照）。
- スクロール追従型フローティングバーやサイドバーボタンにより、1クリックで「下書き（仮登録）」または「本登録」が可能。

### ⚖️ データの比較 ＆ 傾向分析 (専用画面)
- **試料間マトリクス比較**: 選択した複数サンプルの合成条件・保管場所・組成比を横並び比較。
- **測定プロット重畳比較**: XRD, MPMS, PPMS, CV, Raman データの重ね描き比較および CSV ダウンロード。
- **物質特性比較**: 結晶構造・物性パラメータの並列比較。

### 📂 仮登録・データ管理・編集 (1ページ統合管理)
- 下書き保存（仮登録）データおよび正式登録された全データを 1 ページで一括管理。
- 対象レコードを選択すると、**元の登録画面と全く同じフル機能UI**がロードされ、直感的な入力・数値変更・本登録昇格保存が行えます。

### 📋 タスク ＆ カレンダー管理 (親子サブタスク対応)
- 親タスクと小タスク（サブタスク）の階層管理。
- 関連文献や関連イベントのダイレクトリンク、カレンダー表示。

### 💬 開発フィードバック ＆ システムログ
- アプリ内から開発者へ新機能のご要望や不具合報告を送信（送信後も連続入力可能）。
- 発生した自動エラーログの追跡・管理。

## プラグインシステム

### 測定プラグイン一覧 (`plugins/measurements/`)

| 測定タイプ | プラグインファイル | 解析・抽出機能 |
|---|---|---|
| **XRD** | `xrd.py` | RAW/CSV 読込, `pybeads` BG 除去, CIF 重畳, hkl ミラー指数付記, CSV 出力 |
| **SEM** | `sem.py` | JSM-IT700HR PDF 定量抽出, at% 規格化による組成比 (Stoichiometry) 自動計算 |
| **Microscope** | `microscope.py` | 光学/AFM/TEM/SEM 画像 (.png, .jpg, .tif, .bmp) パース ＆ 倍率情報保持 |
| **Raman** | `raman.py` | Raman shift [cm⁻¹] vs 強度 [a.u.], `pybeads` ベースライン除去, ピーク検出 |
| **Laue** | `laue.py` | 結晶方位 [hkl] 解析写真 (.png/.jpg) ＆ PowerPoint (.pptx) 管理 |
| **Electrochemistry** | `electrochemistry.py` | CV (E [V] vs I [μA]) ＆ GCD/PS (t [min] vs I [μA]) 自動パース |
| **PPMS (4端子)** | `ppms_4probe.py` | 温度 T [K] vs 抵抗 R [Ω] / 抵抗率 ρ, 超伝導 Tc, RRR 算出 |
| **PPMS (6端子)** | `ppms_6probe.py` | ホール効果 Vxy - H フィッティング, ホール係数 RH, 伝導型(p/n), キャリア密度 n, 移動度 μ |
| **ShiftCurrent** | `shift_current.py` | 光電応答 I - V, ゼロバイアス光電流 Isc 補間算出 |
| **MPMS** | `mpms.py` | M - T (FC/ZFC, 磁化率 χ), M - H 磁化曲線, μB/f.u. 単位換算 |

```
│   ├── material.py
│   ├── event.py

```
